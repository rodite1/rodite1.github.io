# 文章写作模板（公开文章 / 隐藏加密文章）

本站是 Hugo + PaperMod，文章分两种：

| 类型 | 存放位置 | 说明 |
| --- | --- | --- |
| 公开文章 | `content/posts/` | 正常发布，进首页列表、归档、标签、搜索、RSS |
| 隐藏加密文章 | `content/secret/` | 构建后自动加密进 `public/secret.json`，需口令解锁才能看 |

> 复制下面代码块到新文章里即可。新建文件后，把 `draft = true` 改成 `false` 才会正式发布。

---

## 一、公开文章（content/posts/）

新建文件：`content/posts/文件名.md`
文件名就是 URL 的一部分：`content/posts/建站后发牢骚.md` → `https://rodite1.github.io/posts/建站后发牢骚/`
文件名默认也是标题（front matter 的 `title` 可覆盖）。

### 模板 A：标准文章（推荐）

```toml
+++
date = '2026-11-25T20:00:00+08:00'   # 发布时间；带 +08:00 按中国时间显示（页面显示为 2026-11-25）
draft = false                         # true = 草稿，不发布
title = '文章标题'
categories = ['随笔']                  # 可选：分类（分类页展示）
tags = ['标签1', '标签2']              # 可选：标签（标签页展示）
description = '一句话摘要（可选，用于搜索与分享预览）'
+++
```

### 模板 B：极简文章

```toml
+++
date = '2026-11-25T20:00:00+08:00'
draft = false
title = '文章标题'
+++
```

### 正文骨架（常用 Markdown）

```markdown
## 小标题一

正文段落……

> 引用的一句话——出处

- 列表项一
- 列表项二

## 小标题二

正文段落……
```

### 可选字段

| 字段 | 作用 |
| --- | --- |
| `description` | 摘要，用于搜索与分享预览 |
| `comments = false` | 关闭本篇评论区 |
| `categories` / `tags` | 分类 / 标签，会影响分类页、标签页 |

### 常用 Markdown 速查

| 效果 | 写法 |
| --- | --- |
| 二级标题 | `## 标题`（不要用 `#`，页面大标题已经有了） |
| 加粗 / 斜体 | `**文字**` / `*文字*` |
| 链接 | `[文字](https://example.com)` |
| 图片 | `![说明](/images/图片.jpg)`（图片放 `static/images/` 下） |
| 代码块 | ` ```js … ``` ` |
| 分隔线 | `---` |

## 二、隐藏加密文章（content/secret/）

新建文件：`content/secret/文件名.md`
文件名（去掉 `.md`）默认就是解锁后显示的标题；想用别的标题就写 `secretTitle`。
正文在构建时会被 `scripts/encrypt-secret.mjs` 整体加密，页面源码里只有占位信息，未验证者看不到、也搜不到。

### 模板

```toml
+++
title = "🔒 隐藏内容"                          # 必须是这个占位符，不能写真实标题
description = "该内容已加密，验证口令后查看"    # 占位说明
robotsNoIndex = true
draft = false
# secretTitle = "解锁后显示的真实标题（可选；不写则用文件名）"
# date = 2026-11-25                          # 可选：解锁后文章页显示日期
# tags = ['私密']
# categories = ['日记']
+++
```

正文照常写 Markdown，写法和公开文章一样。

### 注意事项

- **`title` 必须写占位符 `"🔒 隐藏内容"`**：它会被公开渲染进页面 `<title>`，写真实标题等于公开泄露。真实标题用文件名或 `secretTitle` 提供（这两处只随内容加密）。
- 新隐藏文章会自动出现在首页（🔒 卡片）和搜索页隐藏区；首页、搜索页、文章页用同一个口令解锁。
- 解锁口令：用户 / 坐标 / 时间 三段（当前为 `FQY` / `HYSX` / `2018`）。
- 本地预览/构建要跑加密步骤（见下方"发布流程"），否则 `public/secret.json` 是明文。
- 隐藏文章不会进 RSS、sitemap、JSON-LD，搜索引擎抓不到。

## 三、用命令快速新建（自动套用 archetype）

模板已固化在 `archetypes/posts.md` 和 `archetypes/secret.md`，用命令新建会自动生成 front matter：

```powershell
# 公开文章
& "C:\Users\33795\scoop\apps\hugo-extended\current\hugo.exe" new content posts/文件名.md

# 隐藏加密文章
& "C:\Users\33795\scoop\apps\hugo-extended\current\hugo.exe" new content secret/文件名.md
```

生成的 `title` 默认取文件名，`date` 取当前时间，`draft = true`（写完后改 `false`）。

## 四、发布流程

1. 本地预览（可选）：
   - 只检查公开文章/排版：`hugo server` 即可：
     ```powershell
     & "C:\Users\33795\scoop\apps\hugo-extended\current\hugo.exe" server --cacheDir "C:\Users\33795\Desktop\File\myblog-DSH\.hugocache"
     ```
     浏览器打开 `http://localhost:1313`；草稿要加 `-D` 才能预览。
   - **要测试隐藏文章的口令解锁，不能只用 hugo server**（它输出的 `/secret.json` 是明文索引，前端必然报"密码或口令错误"，而且会把 `public/secret.json` 覆盖成明文）。正确流程：
     ```powershell
     # 1. 构建 + 加密
     & "C:\Users\33795\scoop\apps\hugo-extended\current\hugo.exe" --minify --cacheDir "C:\Users\33795\Desktop\File\myblog-DSH\.hugocache"
     node scripts/encrypt-secret.mjs public
     # 2. 用静态服务器打开成品（scripts/serve.mjs，端口默认 8080）
     node scripts/serve.mjs
     ```
     浏览器打开 `http://localhost:8080/`，此时隐藏文章的解锁和线上一致（口令：用户 `FQY` / 坐标 `HYSX` / 时间 `2018`，三个框分开填）。
2. 文章 `draft = false`，确认无误。
3. 提交并 push 到 `main`：GitHub Actions 会自动构建并发布（含隐藏文章的加密步骤），无需手动操作。
