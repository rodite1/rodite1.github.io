# 决策点

## 2026-11-15 首页改版方案（已确认执行）

**目标**：参考 https://ruijian-huang.github.io/（Hexo Butterfly 主题）的设计、排版与细节，美化本站；颜色与主题色沿用原来的暗色毛玻璃（rgba(30,30,30) + 白/灰文字，无彩色强调色）。

**关键决定**：

1. 弃用 `layouts/partials/extend_footer.html` 里「运行时用 JS 重写 DOM」的方案（脆弱、难维护），改为 Hugo 模板原生实现：
   - `layouts/index.html` + `layouts/partials/home/`（hero、post-card、sidebar）
   - 覆盖 `layouts/partials/footer.html`（访客统计 + slogan + 保留 PaperMod 全部脚本）
   - 样式统一收敛到 `assets/css/extended/custom.css`（PaperMod 只加载 `extended/` 目录）
2. 新首页结构（对齐参考站）：首屏 hero（头像/大标题/打字副标题/文章标签分类统计/社交图标/下滑箭头）→ 双栏（左：带封面图的文章卡片，悬停上浮；右：侧边栏小组件）→ 页脚统计。
3. 侧边栏组件：个人资料、公告、最新文章、分类、标签、归档、网站信息、隐藏区解锁。
4. 全部保留原有特效与功能：轮播背景（bg1-5）、雪花、打字机、背景音乐、隐藏区登录（FQY/HYSX/2018）、不蒜子统计、点赞。
5. 新增配置项（hugo.toml）：heroSubtitle、startDate（运行天数）、defaultCovers（卡片封面轮换）、profile、sidebar.announcement、DateFormat。
6. 新增 `content/archives.md`（原来缺失，/archives/ 一直是 404）。
7. 覆盖 `layouts/archives.html`：归档月份中文化（"2026 年 9 月"）。
8. 给两篇文章补了最小分类/标签（日常分享/随笔），沿用旧侧边栏里出现过的词。
9. 未部署、未提交、未推送；如需上线由用户自行 push。

## 2026-11-15 首页二改 + 特效/搜索改造（已确认执行）

1. **首页极简**：`layouts/index.html` 只渲染 hero；`hero.html` 只保留轮播背景 + 站名 + 打字机。头像、统计、社交图标、下滑箭头、音乐按钮、文章卡片列表、侧边栏全部从首页移除（`home/post-card.html`、`home/sidebar.html` 文件保留未删，便于日后恢复）。首页隐藏页脚（footer.html 加 `.IsHome` 条件），导航栏保留。
2. **打字机循环**：打出（140ms/字）→ 停顿 1.8s → 缓缓退格（80ms/字）→ 停顿 0.6s → 无限循环。
3. **文章页不显示封面图**：覆盖 `layouts/_default/single.html`（去掉 cover partial）。
4. **鼠标特效**：全站银白色粒子拖尾（`#cursor-trail` canvas，尊重 prefers-reduced-motion）；文章页（.post-single）悬停显示粉红爱心光标（SVG data URI），链接保持 pointer。
5. **搜索只搜文章 + 隐藏内容验证**：
   - `layouts/_default/index.json` 只索引 posts 文章；新增 `layouts/index.secretjson.json` 输出 `/secret.json`（hugo.toml 加 secretjson 输出格式），只索引 secret 文章。
   - 覆盖 `layouts/search.html`：自定义搜索框（新 id，避免与 PaperMod fastsearch.js 冲突），防抖子串搜索 + 高亮；搜索页放「隐藏区域解锁」表单（FQY/HYSX/2018），验证成功 sessionStorage 记录并加载 secret.json 合并搜索，未验证搜不到隐藏内容。
   - 注意：纯静态站只能做前端验证；secret.json 与隐藏文章 URL 本身仍可被直接访问，与既有机制安全等级一致。
6. **背景音乐**：按「首页只保留站名+打字机」要求，首页音乐按钮已移除（音频元素一并移除）；如需恢复可加回。
7. 未部署、未提交、未推送。
