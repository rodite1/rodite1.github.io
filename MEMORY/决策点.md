**目标**：参考 https://ruijian-huang.github.io/（Hexo Butterfly 主题）的设计、排版与细节，美化本站；颜色与主题色沿用原来的暗色毛玻璃（rgba(30,30,30) + 白/灰文字，无彩色强调色）。

**关键决定**：

1. 弃用 `layouts/partials/extend_footer.html` 里「运行时用 JS 重写 DOM」的方案（脆弱、难维护），改为 Hugo 模板原生实现：
   - `layouts/index.html` + `layouts/partials/home/`（hero、post-card、sidebar）
   - 覆盖 `layouts/partials/footer.html`（访客统计 + slogan + 保留 PaperMod 全部脚本）

2. 新首页结构（对齐参考站）：首屏 hero（头像/大标题/打字副标题/文章标签分类统计/社交图标/下滑箭头）→ 双栏（左：带封面图的文章卡片，悬停上浮；右：侧边栏小组件）→ 页脚统计。
3. 侧边栏组件：个人资料、公告、最新文章、分类、标签、归档、网站信息、隐藏区解锁。
4. 全部保留原有特效与功能：轮播背景（bg1-5）、雪花、打字机、背景音乐、隐藏区登录（FQY/HYSX/2018）、不蒜子统计、点赞。
5. 新增配置项（hugo.toml）：heroSubtitle、startDate（运行天数）、defaultCovers（卡片封面轮换）、profile、sidebar.announcement、DateFormat。
6. 新增 `content/archives.md`（原来缺失，/archives/ 一直是 404）。
7. 覆盖 `layouts/archives.html`：归档月份中文化（"2026 年 9 月"）。
