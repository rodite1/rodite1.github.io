## 2026-11-15 三改：恢复首页排版 + 隐藏内容加密收紧（已确认执行）

1. **恢复首页排版**（用户明确要求"能向下滑，和原先版本一样"）：`layouts/index.html`、`layouts/partials/home/hero.html` 恢复为初改版式（hero 全屏 → 双栏文章卡片+侧边栏 → 页脚），`footer.html` 恢复首页显示页脚，音乐按钮恢复。打字机循环保留。
2. **隐藏内容前端加密**（用户确认"那就做好吧"）：
   - `scripts/encrypt-secret.mjs`：构建后把 Hugo 生成的明文 secret 索引加密为 AES-256-GCM 密文（PBKDF2-SHA256，150000 次，salt 随机）。口令默认 `FQY:HYSX:2018`，可用 `SECRET_PASSWORD` 环境变量覆盖。
   - 前端 `SecretVault`（Web Crypto）模块定义在 extend_footer.html：输对口令=能解密（GCM 认证即验证），解锁密钥存 sessionStorage 跨页共享；首页解锁显示隐藏卡片、搜索页解锁合并隐藏条目、隐藏文章页解锁渲染正文。
   - 明文防护清单：RSS 排除 secret（layouts/rss.xml）；sitemap 排除（layouts/sitemap.xml）；JSON-LD 不输出 secret（覆盖 layouts/partials/templates/schema_json.html）；/secret/ 列表页改提示页（layouts/secret/list.html）；secret 文章页静态只有锁定表单（layouts/secret/single.html）；首页 secret 卡片只渲染骨架（post-card.html 的 data-secret-title）；secret 文章 front matter 标题用占位符 🔒（真实标题=文件名，随正文一起加密）。
   - GitHub Actions：Build 后新增 `node scripts/encrypt-secret.mjs public` 步骤（SECRET_PASSWORD 可选 secret，未配置时脚本回退默认口令）。
   - 安全边界（已向用户说明）：纯静态站无法做到绝对保密——密钥由口令派生，口令本身弱（FQY/HYSX/2018）可被离线暴力破解；但明文不再出现在任何公开产物（HTML/RSS/sitemap/JSON-LD/索引），未验证者无法看到或搜索到。要更强只能换强口令（改动 = 设 SECRET_PASSWORD + 前端表单口令相同）。
3. 保留全部既有效果：循环打字机、文章页无封面图、银白拖尾、爱心光标、搜索只搜文章、点赞、不蒜子、雪花、轮播、音乐。
4. 未部署、未提交、未推送。
